# Upstream

This directory contains the distribution from `Cyrene2008/swarm-cursors-vue` 1.4.0 at Git commit `da7a2b4b765d652ce0f57e48c714cabab8cf20a0`. CyTime's Bun file dependency installs these files without contacting the package's GitHub repository or relying on an npm release. The local manifest is private and omits upstream build and publishing configuration; the runtime files and license are unchanged.

To update it, replace the complete upstream distribution together (including `dist/chunks/` and both license files), update this pin, and regenerate CyTime's Bun lockfile. Keep the license and notice in `public/licenses/swarm-cursors-vue/` in sync for web distributions.
